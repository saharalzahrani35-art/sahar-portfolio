# Sahar Alzahrani — Portfolio

A bilingual, responsive portfolio prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload this project or push it to the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. The included workflow publishes the `dist` directory automatically.

## Update content

- Page copy and project links: `dist/index.html`
- Colors and layout: `dist/styles.css`
- Language and navigation behavior: `dist/script.js`
- Résumé file: `dist/assets/Sahar-Alzahrani-CV-Arabic.pdf`

Project covers currently load from Sahar's own Behance profile. Replace them with optimized local images before the final public launch if desired.
